# 🐰⚡ Bug Invaders: CodeRabbit × Google Arcade Edition

Un juego Arcade retro-futurista inspirado en **Space Invaders** y **Galaga**, construido con **HTML5 Canvas + Vanilla JS + Web Audio API** (cero dependencias externas).

Defiende la rama `main` de producción piloteando el **CodeRabbit Astro-Defender**, protégela detrás de tus escudos de **CI/CD (`UNIT TESTS`, `LINTER`, `TYPECHECK`, `CI/CD GATE`)** y destruye oleadas de bugs antes de que tiren producción.

---

## 🚀 Cómo jugar

Puedes abrir directamente el archivo `index.html` en cualquier navegador moderno, o levantarlo con un servidor local:

```bash
# Opción 1: Abrir directamente en macOS
open index.html

# Opción 2: Servidor local con Python
python3 -m http.server 8080
# Luego abre http://localhost:8080
```

## 👾 Tipos de Bugs y Jefes

* **Merge Conflict (`<<<<<<<` - 60 PTS):** Élite carmesí en la fila superior. Rompe la formación al estilo *Galaga* para lanzarse en picada disparando conflictos.
* **Memory Leak (45 PTS):** Al ser destruido con disparos normales se divide en **2 mini-leaks** rápidos (usa el *Gemini Pierce Beam* o una *1-Click Bomb* para desintegrarlo sin dividirse).
* **Race Condition (30 PTS):** Avispa amarilla/cian que hace *phase-shift* horizontal errático.
* **Null Pointer Exception (20 PTS):** Escarabajo clásico de marcha implacable.
* **🛸 Friday 5PM Deploy UFO (350 PTS):** Cruza la parte superior con alarma. Derribarlo salva el fin de semana y suelta un **Power-Up garantizado**.
* **🚨 Jefes cada 3 Oleadas (`The Spaghetti Monolith` y `Tech Debt Hydra`):** Apunta a la caja verde **`2X CRIT`** escaneada por CodeRabbit para hacer **2.5x de daño crítico**.
